# Hey, I'm Nate 👋

Student developer from South Africa, moving to the UK. I build small tools that fix things that annoy me, mostly on Android TV and macOS, and I contribute to open source apps I use every day.

🌐 [glasby.me](https://glasby.me)

## 🛠️ Projects

| Project | What it does |
| --- | --- |
| [SpaceFS Portable](https://github.com/NathanGlasby/spacefs-portable) | Mount your Space drive as a local folder from a portable app, no install needed |
| [Dropbox Portable](https://github.com/NathanGlasby/dropbox-portable) | Unofficial portable app that mounts your Dropbox as a drive, powered by rclone |
| [AirPodsOverlayATV](https://github.com/NathanGlasby/AirPodsOverlayATV) | iPhone style AirPods connect popup for Android TV, with battery, ANC and auto-pause |
| [tv-ringlight](https://github.com/NathanGlasby/tv-ringlight) | Soft glowing ringlight overlay around your TV screen, triggered from Button Mapper |
| [driveplay-keeper](https://github.com/NathanGlasby/driveplay-keeper) | Keeps Spotify playing when starting the car pauses Android Auto |
